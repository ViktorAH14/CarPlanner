# CarPlanner

> Приложение для учёта расходов на автомобиль: заправки, ТО, ремонты, средний расход топлива и напоминания о техобслуживании.

## 🚀 О проекте

CarPlanner — это кроссплатформенное приложение (Android, Windows, Linux) для управления расходами на автомобиль. Оно помогает отслеживать заправки, рассчитывать средний расход топлива, вести учёт любых трат по машине и не пропускать сроки технического обслуживания благодаря умным напоминаниям.

Приложение поддерживает синхронизацию данных между всеми устройствами пользователя и работает в офлайн-режиме: все изменения сохраняются локально и отправляются на сервер при появлении интернета.

**Стек:** <br>
Flutter (Frontend) + Node.js + Express (Backend) + PostgreSQL (Database).
